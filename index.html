🚀 Async-First

Built-in async/await primitives make concurrent programming intuitive. Spawn tasks with Vibe, await with Chill.

🌐 Networking Built-In

First-class support for HTTP (Spit, Yeet, Flex, Ghost) and TCP operations (Listen, Holla, Peek, Whisper).

⚡ High Performance

SIMD-accelerated JSON parsing, high-performance regex engine, and optimized I/O operations.

🎨 Vibe-Based Syntax

Memorable keywords inspired by urban slang make code expressive and fun. Ayo, Bruh, Maybe, Crazy, and more!

🔧 Developer Experience

VS Code extension with syntax highlighting, LSP support, code completion, and error diagnostics.

📁 Rich I/O

Comprehensive file operations (Snag, Stash, KeepAdding, Trash) and powerful regex support.
