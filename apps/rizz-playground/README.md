# RizzScript Playground

An online code sandbox for RizzScript with a WASM-based interpreter, similar to the Go Playground.

## Features

- 🎨 **Monaco Editor** - Full-featured code editor with syntax highlighting
- ⚡ **WASM Runtime** - Fast, native Rust-based code execution in the browser
- 📱 **Responsive Design** - Works on desktop and mobile
- 🎯 **Example Scripts** - Learn RizzScript with interactive examples
- 🔄 **Real-time Output** - See results instantly

## Prerequisites

- Node.js 18+ and npm
- Rust toolchain (for building WASM)
- wasm-pack (will be installed automatically if missing)

## Getting Started

### 1. Build WASM Module

First, build the WASM module and copy it to the public folder:

```bash
# Using npm script
npm run build:wasm

# Or using the shell script directly
./scripts/build-wasm.sh

# Or using Node.js script
node scripts/build-wasm.js
```

This will:
- Build the Rust WASM module using `wasm-pack`
- Copy all WASM files to `public/wasm/`
- Make them available for the playground to load

### 2. Install Dependencies

```bash
npm install
```

### 3. Start Development Server

```bash
npm run dev
```

The playground will be available at `http://localhost:5173/`

### 4. Build for Production

```bash
# Build WASM and then build the app
npm run build:all

# Or separately
npm run build:wasm
npm run build
```

## How It Works

### WASM Integration

The playground uses a two-tier approach:

1. **Primary**: Tries to load WASM module from `/wasm/rizz_wasm.js`
2. **Fallback**: Uses JavaScript interpreter if WASM is unavailable

The WASM module provides:
- Native Rust performance
- Full RizzScript parser and runtime
- Better error messages
- Type safety

### File Structure

```
rizz-playground/
├── public/
│   └── wasm/              # WASM files (generated by build script)
│       ├── rizz_wasm.js   # WASM bindings
│       ├── rizz_wasm_bg.wasm  # WASM binary
│       └── ...
├── src/
│   ├── runtime/
│   │   └── interpreter.ts  # WASM/JS interpreter wrapper
│   └── ...
└── scripts/
    ├── build-wasm.sh      # Shell build script
    └── build-wasm.js      # Node.js build script
```

## Building WASM

The build process:

1. **Compiles Rust to WASM**: Uses `wasm-pack build --target web`
2. **Optimizes**: Release build with size optimizations
3. **Copies**: Moves files to `public/wasm/` for Vite to serve

### Manual Build

If you need to build manually:

```bash
cd ../rizz-wasm
wasm-pack build --target web --release
cp -r pkg/* ../rizz-playground/public/wasm/
```

## Troubleshooting

### WASM Not Loading

If you see "Failed to load WASM module" in the console:

1. **Check files exist**: Verify `public/wasm/rizz_wasm.js` exists
2. **Rebuild WASM**: Run `npm run build:wasm`
3. **Check browser console**: Look for CORS or loading errors
4. **Verify Vite config**: Ensure WASM plugins are enabled

### Build Errors

If WASM build fails:

- **Tokio dependency**: Currently, `rizz-core` uses Tokio which doesn't compile to WASM
- **Workaround**: The playground falls back to JS interpreter automatically
- **Future**: Once `rizz-core` is refactored with feature flags, WASM will work fully

### Development vs Production

- **Development**: WASM files are served from `public/wasm/`
- **Production**: Build script copies WASM files before Vite build
- **Vite**: Automatically handles WASM imports and optimization

## Example Usage

```typescript
import { createInterpreter } from './runtime/interpreter';

const interpreter = await createInterpreter();
const result = await interpreter.execute(`
  Ayo x = 42
  Rizz("The answer is: " + x)
`);

console.log(result.stdout); // ["The answer is: 42"]
```

## Performance

Expected performance with WASM:

- **Parse Time**: ~0.5ms (vs ~5ms JS)
- **Execution**: 10-100x faster than JS
- **Memory**: Lower overhead
- **Bundle Size**: ~200KB gzipped
